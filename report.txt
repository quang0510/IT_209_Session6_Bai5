================================================================================
BÁO CÁO THỰC HIỆN BÀI 5: THIẾT KẾ VÀ CẤU HÌNH SYSTEMD SERVICE CHO ỨNG DỤNG JAVA
================================================================================

1. TỔNG QUAN CẤU HÌNH
- Tên dịch vụ: java-app.service
- Đường dẫn file service: /etc/systemd/system/java-app.service
- Tài khoản thực thi: java-runner (tài khoản hệ thống không có quyền đăng nhập shell)
  Lệnh tạo: sudo useradd -r -s /usr/sbin/nologin java-runner
- Chính sách restart: on-failure, RestartSec=10s
- Mô phỏng ứng dụng Java: Chạy lệnh xuất log khởi tạo với user hiện tại và duy trì tiến trình bằng sleep 3600.

--------------------------------------------------------------------------------
2. NỘI DUNG TỆP CẤU HÌNH /etc/systemd/system/java-app.service
--------------------------------------------------------------------------------
[Unit]
Description=Java Application Service (Spring Boot)
After=network.target

[Service]
Type=simple
User=java-runner

# Thuc thi mo phong ung dung Java (in log xac nhan user va chay nen)
# Trong moi truong san pham thuc te, su dung lenh chay jar nhu sau:
# ExecStart=/usr/bin/java -jar /opt/app/app.jar
ExecStart=/bin/bash -c "echo 'Java application started successfully under user: '$(whoami); exec /usr/bin/sleep 3600"

# Chinh sach tu dong khoi dong lai khi gap su co
Restart=on-failure
RestartSec=10s

[Install]
WantedBy=multi-user.target

6. ĐÁNH GIÁ KẾT QUẢ THEO YÊU CẦU ĐỀ BÀI
--------------------------------------------------------------------------------
[x] Tài khoản java-runner được tạo thành công với cờ -r (system user) và -s /usr/sbin/nologin (chặn đăng nhập shell).
[x] Tệp cấu hình /etc/systemd/system/java-app.service đầy đủ các khối [Unit], [Service], [Install].
[x] Quyền thực thi dưới user java-runner (User=java-runner).
[x] Trạng thái dịch vụ đạt Active: active (running).
[x] Log journalctl ghi nhận tiến trình được thực thi dưới quyền user java-runner.
[x] Chính sách khởi động lại (Restart=on-failure, RestartSec=10s) hoạt động chính xác khi mô phỏng tiến trình bị dừng đột ngột (kill -9).
